# 📚 书巢 BookNest

用手机或电脑摄像头扫书背面的条形码，自动从公开资源抓取书目信息（封面、内容简介、评分、作者、出版时间、出版社…），
按「想读 / 已购 / 在读 / 读过 / 弃读」管理，支持自动分类 + 手动分类，以及带颜色的标签。

**零第三方依赖**（只用 Node 内置模块），数据全部存在你自己电脑的一个 JSON 文件里。

---

## 一、启动

```bash
cd booknest
./start.sh
```

启动后终端会打印访问地址：

```
📚  书巢 BookNest 已启动
手机访问（同一 Wi-Fi，推荐）: https://<本机IP>:8787
电脑访问: http://localhost:8788
```

- **电脑**：直接打开 `http://localhost:8788`（localhost 属于安全上下文，摄像头可直接用）。
- **手机**：手机连同一个 Wi-Fi，打开终端里那个 `https://192.168.x.x:8787`。
  首次会提示「证书不受信任」→ 选择「继续访问 / 高级 → 继续前往」。
  如果浏览器仍拒绝摄像头（部分 Android Chrome 对自签证书很严格），用页面里的 **📷 拍照识别条码**，或
  在 Chrome 中打开 `chrome://flags/#unsafely-treat-insecure-origin-as-secure`，把该地址加入白名单。

> 需要 Node.js 18+（代理功能需要 24+）。脚本会自动在 PATH、`~/.dsh` 运行时、Homebrew 目录里找 `node`。
> macOS 首次运行可能弹「是否允许 node 接受传入网络连接」→ 选「允许」，否则手机连不上。

**关于代理（国内网络）**：Google Books / Open Library 在国内访问不了，脚本会自动探测本机常见代理端口
（7890 / 7897 / 10809 / 8888…），探到就自动为这两个海外源挂上代理，豆瓣和微信读书仍然直连：

```
🌐 海外数据源（Google Books / Open Library）走代理：http://127.0.0.1:7890  [自动探测]
```

想手动指定或关闭：

```bash
BOOKNEST_PROXY=http://127.0.0.1:7890 ./start.sh   # 指定代理
BOOKNEST_PROXY=off ./start.sh                     # 关闭代理
```

也可以在页面「设置 → 网络代理」里填写/关闭（保存后需要重启服务生效）。

**停止服务**：

```bash
cd booknest
./stop.sh          # 推荐：先发 SIGTERM 让服务保存数据再退出，10 秒没退出才强杀
```

也可以直接在运行 `start.sh` 的终端按 `Ctrl+C`。数据会实时落盘，不会丢。

## 二、怎么用

1. 底部 **扫码** → 会自动打开摄像头，把书背面条码放进取景框。
   - 识别成功会「滴」一声并振动，然后自动联网获取书目信息。
   - 识别不了？可以用 **📷 拍照识别条码**（对焦拍一张，本地解码）。
   - 也可以 **⌨️ 手动输入 ISBN**，或直接 **按书名搜索**（会列出豆瓣/微信读书的候选让你挑）。
   - 支持蓝牙扫码枪：在任意页面扫码枪输入数字并回车即可。
2. 弹出的确认页里：
   - 选状态（想读 / 已购 / 在读 / 读过）；
   - 分类默认给一个**自动建议**（基于书名、简介、来源分类关键词打分），可一键采用或换成自己的分类；
   - 打标签（可现场新建，选颜色）；
   - 点 **保存到书架**，或 **保存并继续扫** 连续录入。
   - 「详细信息」里所有字段都能手改（书名、作者、出版社、页数、定价、存放位置、我的评分、备注…）。
   - **离散字段即时保存**：状态 / 分类 / 标签 / 加入书单 / 我的评分 / 阅读进度 点一下**立刻生效**，不用再翻到底部点保存；
     顶部会显示「✓ 已保存 / ● 保存中… / ⚠ 保存失败」（失败会自动回滚界面）。文字类内容（书名、作者、简介、备注…）改完仍需点底部
     「保存文字修改」，两者互不干扰。点选控件只做局部更新，所以**不会跳回页面顶部**、也不会打断正在输入的内容。
   - **点作者/译者的名字**（详情页顶部的小胶囊）会列出 TA 的**全部作品**，可以直接挑着加入书架：
     - 数据来自 **豆瓣作者作品接口**（`/rexxar/api/v2/author/<id>/works`，带总数、按评分排序，如余华 87 部、刘慈欣 133 部）+ **微信读书**（豆瓣对译者没有作品列表，译者的书靠微信读书的 author 字段，如译者袁国忠）+ **Open Library**（拉丁字母作者名）；
     - 列表标注来源徽章与评分，**已经在书架里的会显示绿色「已在书架」**（点它跳到那本书），其余的显示「＋ 加入」，点一下走正常抓取确认流程；
     - 加完书后列表里的「已在书架」标记会自动刷新。结果缓存 3 天。
   - **点封面可放大**：全屏查看大图，再点图片可放大到 2 倍多并拖动看细节；点空白处 / ✕ / Esc 关闭。
   - 详情页最下面有 **相似的书目**：
     - **书架里**（本地实时计算，不联网）：按 同分类 +3 / 共同标签 ×2 / 同作者 +3 / 同丛书 +2 / 同出版社 +0.5 / 书名相近 +2 打分，并标出理由（如「同类 · 艺术与设计 · 共同标签 · 借来的」），点一张就跳到那本书的详情；
     - **相关推荐**（懒加载，缓存 3 天，右上 ↻ 换一批）**合并三个来源**，每张卡片标注来源与理由：
       - **豆瓣「喜欢这本书的人也喜欢」**（移动版 rexxar 接口，信号最强：`活着` → 平凡的世界 / 围城 / 我与地坛 / 许三观卖血记…）；
       - **豆瓣联想 + 微信读书搜索**：同系列 / 其他版本 / 书名相近 / 同一作者（自动过滤同名网文、山寨书）；
       - **Open Library**：同作者的其它作品；以及**同主题读者也在读**（按主题取最受好评的书，如 `computer programming` → 程序员修炼之道 / SICP / K&R C，`popular science` → 时间简史 / 万物简史）。
     - 每个来源有配额（读者也喜欢 5 / 同系列 3 / 同作者 2 / 同主题 2），保证多源都能露脸；**已在书架里的书和自己都会被排除**；点一张即可查看并加入书架。
3. **没有条码的书 → 扫封面识别**：扫码页点「📖 没有条码？扫封面识别」，拍一张封面照片，系统会：
   - 在**本机**做 OCR（不上传云端），两种引擎自动切换：
     - **macOS**：系统自带 **Vision** 框架（零安装，中文最准，约 0.6 秒）；
     - **Linux/Ubuntu**：**Tesseract OCR**（`sudo apt install tesseract-ocr tesseract-ocr-chi-sim`）。默认语言只用 `chi_sim`——实测中文封面上它比 `chi_sim+eng` 准得多（加了英文模型，大号汉字会被识别成 `AWE`、`Mopi2l Lit` 这类拉丁乱码），而英文封面它同样认得住；
     - 都不可用时给出安装提示，并退化成手动输入书名；
   - 自动挑出最像书名的文字（过滤掉作者、出版社、定价、"著/译"等噪声行）去豆瓣/微信读书搜索；
   - 按 **书名相似度 85% + 作者名是否出现在封面上 15%** 排序，列出候选书目（含封面缩略图与匹配度）让你确认；
   - 选中后按正常流程抓取完整元数据；都不对可以现场输书名重搜。
   - 同时可勾选「查不到官方封面时，用这张封面照片当封面」——老书、无条码书、绝版书拿不到官方封面时，直接拿你拍的照片当封面。
   - 已有书籍也能补封面：打开书籍详情 → 「📷 用照片当封面」。
4. **书单**：底部「书单」页签可以建任意多个主题书单（例如「明朝那些事系列」「待读的商业书」）：
   - 点 **＋ 新建书单** 填名称/说明、选颜色；
   - 进书单点 **＋ 添加 / 管理书籍**，在书架里勾选（可搜索）；取消勾选就是从书单移出；
   - 这个选书列表**可以排序**：默认「最近添加」（最后加进书架的书排在最前），另有 最早添加 / 最近更新 / 已在书单优先 /
     书名 A→Z / 作者 A→Z / 公开评分 / 我的评分 / 出版时间（新→旧、旧→新）/ 阅读状态；按加入时间排序时每行还会显示加入日期，
     选择会被记住下次沿用；
   - 书单**头部实时统计进度**：`已读 3/10` + 进度条，另有「未读 / 在读 / 想读 / 已购未读」细分；
   - 每个书单可单独**排序**：最近加入 / 最早加入 / 公开评分 / 我的评分 / 书名 / 作者 / 出版时间（新→旧、旧→新）/ 阅读状态；
   - 书籍详情页也有「加入书单」区域，可直接勾选归属；删除书籍会自动从所有书单剔除。
5. 书架页：搜索（书名/作者/出版社/ISBN/标签），按状态、分类、标签筛选，按最近添加/书名/作者/评分/出版时间排序；
   右上角切换 **网格 / 列表 / 按分类分组** 三种视图。
6. **管理** 页：增删改分类和标签（名称 + 颜色），还能「⚡ 为 N 本未分类的书套用自动分类」。
7. **统计** 页：藏书总量、各状态分布、分类分布、标签使用、总页数/已读页数、平均评分。
8. **设置** 页：手机访问二维码、网络代理、数据源可用性检测、导出 JSON / CSV、导入 JSON 备份、清空缓存、清空数据。

## 三、书籍信息来源

按顺序降级，结果按来源优先级合并（豆瓣 > 微信读书 > Google Books > Open Library），并做了书名相似度校验，避免串书：

| 来源 | 说明 |
| --- | --- |
| 豆瓣读书 | 解析公开书目页，中文书覆盖最好：封面、内容简介、作者简介、评分与评价人数、出版社、出版年、页数、定价、装帧、译者、丛书。请求间隔 ≥1.2s，失败退避重试，结果本地缓存，同一本书不会反复抓。固定桌面 UA 请求，若被重定向到 m.douban.com 会自动换回桌面版页面。 |
| 微信读书 | 公开搜索接口，补充封面、简介、出版方、推荐值（评分）。 |
| 豆瓣「读者也喜欢」 | 移动版公开接口 `/rexxar/api/v2/book/<id>/recommendations`，用于详情页的"喜欢这本书的人也喜欢"。 |
| Google Books | 官方 API，海外书友好。**国内需走代理**；匿名配额经常被用尽（HTTP 429），在「设置 → 网络代理」填一个免费 API Key 即可恢复，填完立即生效。 |
| Open Library | 公开 API，作为最后的兜底。用稳定的 `search.json` 端点取书目 + `covers.openlibrary.org` 取封面。**国内需走代理。** |

**代理是怎么生效的**：`start.sh` 把 `NODE_USE_ENV_PROXY=1` 与 `HTTPS_PROXY` 注入给 Node，
Node 自带的 `fetch` 便会走代理；同时把 `douban.com / doubanio.com / qq.com / weread.qq.com / localhost`
写进 `NO_PROXY`，保证国内源始终直连。因此：

- 代理没开也不会拖慢国内查询——探测不可用的海外源会被标记并自动跳过（「设置 → 数据源」可随时重新检测），
  豆瓣/微信读书的查询依旧是 1 秒左右返回。
- 只有国内源信息不全时（缺封面/简介），才会等待海外源补充。
- 代理配置在**进程启动时**生效，改完要重启服务；`Ctrl+C` 后重新 `./start.sh` 即可。

- 服务启动时会在后台探测各数据源连通性（结果见「设置 → 数据源」，可手动重新检测）。
- 封面会在入库时下载到本地 `data/covers/`（豆瓣图床有防盗链，必须带 Referer 才能取到，服务已代为处理），
  离线也能看；抓取失败的封面走 `/api/cover` 代理并落盘缓存（只放行图床白名单，且响应必须是图片）。
- 使用提醒：这些信息来自公开页面/接口，仅建议用于**个人藏书管理**，请勿高频抓取或二次分发。

## 四、部署到云端 Ubuntu

完整步骤见 **[deploy/README-ubuntu.md](deploy/README-ubuntu.md)**，配套 systemd 单元 [deploy/booknest.service](deploy/booknest.service)。要点：

```bash
sudo apt install -y tesseract-ocr tesseract-ocr-chi-sim          # 封面识别（中文包必装）
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash - && sudo apt install -y nodejs
sudo cp /opt/booknest/deploy/booknest.service /etc/systemd/system/
sudo systemctl enable --now booknest
```

- **务必设置访问密码**：`BOOKNEST_PASSWORD=你的密码`。设置后页面要登录、接口要 Cookie（支持 `?token=密码` 一次性登录），不设置则和本机自用一样免登录。
- 手机扫码需要安全上下文：推荐 Caddy/Nginx 反代 + 正式证书；也可直接接受自签证书；都不方便就用「拍照识别条码」（不需要 https）。
- 服务器在境内需要 `BOOKNEST_PROXY=http://127.0.0.1:7890` 才能访问海外源；在境外直连即可。
- 启动横幅会打印当前生效的引擎与配置，可据此自检：

```
🔍 封面识别: Tesseract OCR（chi_sim）
🔒 访问密码: 已开启（BOOKNEST_PASSWORD）
运行环境: linux/x64 · Node v24.x
```

- 页面「设置 → 数据源」里也能看到 **封面文字识别引擎 / 运行环境 / 访问密码** 三项状态。

## 五、数据与备份

| 路径 | 内容 |
| --- | --- |
| `data/db.json` | 全部数据：书籍、分类、标签、元数据缓存（原子写入，损坏时自动备份为 `db.json.broken-*`） |
| `data/covers/` | 本地化的封面图片 |
| `certs/` | https 自签证书（`start.sh` 自动生成，与当前局域网 IP 绑定） |

- 换电脑 / 换 Wi-Fi 后 IP 变了：删掉 `certs/` 重新运行 `start.sh` 即可重新生成。
- 备份：设置页「导出 JSON」，恢复用「导入 JSON 备份」（按 ISBN 去重）。
- 表格分析：设置页「导出 CSV」（带 BOM，Excel/Numbers 直接打开不乱码）。

## 七、接口速查（自用/二次开发）

```
GET    /api/bootstrap                 一次性返回书籍、分类、标签、统计、数据源状态
POST   /api/lookup   {isbn|title|source+sourceId,force} 抓取书目元数据（带缓存与降级）
GET    /api/search?q=                 按书名搜索候选（豆瓣 + 微信读书）
GET    /api/author-books?name=        作者/译者的全部作品（豆瓣作者接口 + 微信读书 + Open Library，标记"已在书架"，缓存 3 天）
POST   /api/cover-search              上传封面照片（原始图片 body）→ OCR → 候选书目
POST   /api/uploads                   仅上传图片，返回 token（用于"用照片当封面"）
POST   /api/books/:id/photo-cover     把上传的照片设为该书封面
POST   /api/books                     新增（ISBN 重复返回 409 + 已有书籍）
PATCH  /api/books/:id                 修改任意字段（改状态会自动记录开始/读完时间）
DELETE /api/books/:id                 删除
POST   /api/books/:id/refetch          重新抓取并覆盖元数据字段
GET    /api/books/:id/related          相关推荐（豆瓣读者也喜欢 + 同系列/同作者 + 微信读书 + Open Library，缓存 3 天，?force=1 强制刷新）
GET    /api/export?format=json|csv     导出
POST   /api/import                    导入备份
GET/POST/PATCH/DELETE /api/categories  /api/tags   分类与标签管理
GET    /api/booklists                 书单列表（含 已读/共 进度统计与排序方式）
POST   /api/booklists                 新建书单 {name,description,color}
PATCH  /api/booklists/:id             改名 / 说明 / 颜色 / 排序方式 sort
DELETE /api/booklists/:id             删除书单（不影响书）
POST   /api/booklists/:id/books       往书单加书 {bookIds:[]}（重复与不存在自动跳过）
POST   /api/booklists/:id/books/remove 从书单移出 {bookIds:[]}
POST   /api/auto-categorize           给未分类的书套用自动分类
GET    /api/cover?src=                带 Referer 与磁盘缓存的封面代理（仅放行图床白名单）
POST   /api/providers/check           重新探测海外数据源
```
